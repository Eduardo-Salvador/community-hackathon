# Extensão Tupi Brasil (Chrome)

Liga a sua conta gov.br, aberta **no seu próprio Chrome**, ao assistente. O login é feito por você numa aba normal (sem captcha bloqueado); a extensão só lê o texto das telas do portal da Senatran e envia para a sua conversa.

## Instalar (modo desenvolvedor)

1. Abra `chrome://extensions`.
2. Ligue **Modo do desenvolvedor** (canto superior direito).
3. Clique em **Carregar sem compactação** e escolha esta pasta `extension/`.
4. Fixe o ícone do Tupi Brasil na barra do Chrome.

## Usar

1. No site, peça ao assistente para **conectar a extensão**: ele fala um código de 6 letras.
2. Clique no ícone da extensão, digite o código e **Conectar**.
3. Clique em **Abrir o portal para entrar** e faça login no gov.br normalmente.
4. Volte na extensão e clique em **Sincronizar**: ela abre a CNH, as multas e os veículos, um de cada vez.
5. Volte ao site e pergunte: os dados reais aparecem.

O código vale 10 minutos e só funciona uma vez. Nada é guardado: os dados somem quando a conversa acaba.
